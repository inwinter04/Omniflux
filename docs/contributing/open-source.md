# 开源依赖与致谢

Omniflux 站在众多巨人的肩膀上。我们由衷感谢以下开源项目及其社区维护者的杰出工作！

## 核心底层与引擎

| 项目名 | 官方主页与源码 | 在 Omniflux 中的具体作用 |
| :--- | :--- | :--- |
| **Bifrost** | [github.com/maximhq/bifrost](https://github.com/maximhq/bifrost) | 高性能上游多模型协议适配底座，承载了不同供应商模型协议转换、流式处理与连接管理。 |
